**Анализ данных для агентства недвижимости.**<br>
Агентство недвижимости из Петрозаводска, которое планирует выйти на рынок Санкт-Петербурга и Ленинградской области и перевести основной офис в новый регион. Агентству нужен готовый анализ объявлений о продаже жилой недвижимости в Санкт-Петербурге и Ленинградской области, чтобы найти самые перспективные сегменты недвижимости. Работа происходит с данными схемы real_estate. В ней находится архивная информация сервиса Яндекс Недвижимость: объявления о продаже жилой недвижимости в Санкт-Петербурге и Ленинградской области за несколько лет. <br> 

**В проекте решены ad hoc задачи с помощью SQL-запросов:**<br> 
1. Определить наиболее привлекательные сегменты недвижимости Санкт-Петербурга и городов Ленинградской области, чтобы создать эффективную бизнес-стратегию на рынке недвижимости. Определять эту привлекательность можно по времени активности объявлений.
2. Понять сезонные тенденции на рынке Санкт-Петербурга и городов Ленинградской области, чтобы знать периоды с повышенной активностью продавцов и покупателей недвижимости в регионе. Это поможет спланировать маркетинговые кампании и выбрать сроки для выхода на рынок.<br>

**Описание данных.**<br>
Таблица advertisement содержит информацию об объявлениях:<br>
id — идентификатор объявления (первичный ключ).<br>
first_day_exposition — дата подачи объявления.<br>
days_exposition — длительность нахождения объявления на сайте (в днях).<br>
last_price — стоимость квартиры в объявлении, в руб.<br>

Таблица flats содержит информацию о квартирах:<br>
id — идентификатор квартиры (первичный ключ, связан с первичным ключом id таблицы advertisement).<br>
city_id — идентификатор города (внешний ключ, связан с city_id таблицы city).<br>
type_id — идентификатор типа населённого пункта (внешний ключ, связан с type_id таблицы type).<br>
total_area — общая площадь квартиры, в кв. метрах.<br>
rooms — число комнат.<br>
ceiling_height — высота потолка, в метрах.<br>
floors_total — этажность дома, в котором находится квартира.<br>
living_area — жилая площадь, в кв. метрах.<br>
floor — этаж квартиры.<br>
is_apartment — указатель, является ли квартира апартаментами (1 — является, 0 — не является).<br>
open_plan — указатель, имеется ли в квартире открытая планировка (1 — открытая планировка квартиры, 0 — открытая планировка отсутствует).<br>
kitchen_area — площадь кухни, в кв. метрах.<br>
balcony — количество балконов в квартире.<br>
airports_nearest — расстояние до ближайшего аэропорта, в метрах.<br>
parks_around3000 — число парков в радиусе трёх километров.<br>
ponds_around3000 — число водоёмов в радиусе трёх километров.<br>

Таблица city содержит информацию о городах:<br>
city_id — идентификатор населённого пункта (первичный ключ).<br>
city — название населённого пункта.<br>

Таблица type содержит информацию о городах:<br>
type_id — идентификатор типа населённого пункта (первичный ключ).<br>
type — название типа населённого пункта.
