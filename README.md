Портфолио продуктового аналитика содержит проекты по анализу данных.<br>

**Два проекта на SQL:**<br>
Папка "SQL - ad hoc" содержит анализ данных для агентства недвижимости, решение задач с помощью SQL-запросов. <br>
Папка "SQL - доноры" содержит решение задач с помощью SQL-запросов для проекта DonorSearch. Изучено, какие факторы влияют на активность доноров и какие могут быть стратегии для их мотивации.<br>

**Три проекта на Python:**<br>
Папки "python - ДТП" и "python - ДТП 2" содержат ноутбуки анализа данных некоммерческого проекта «Карты ДТП», посвященному проблемам дорожно-транспортных происшествий в России. Представлены предобработка данных, исследовательские анализы, визуализации, рекомендации и выводы.<br>
Папка "AB тест" содержит подготовку, проведение и анализ А/В тестирования для развлекательного приложения.<br>

**Дашборды:**<br>
Папка "дашборды" содержит ссылки на разработанные мною дашборды в Yandex DataLens.<br> 
 
**Стеки**: <br> 
SQL (включая оконные функции), Python (pandas, matplotlib, seaborn, numpy, scipy, phik  и пр), BI-инструменты (Yandex DataLens).<br>
