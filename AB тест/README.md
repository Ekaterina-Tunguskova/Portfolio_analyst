Компания, которая разрабатывает развлекательное приложение с функцией «бесконечной» ленты, создала новый алгоритм рекомендаций, который, по их мнению, будет показывать более интересный контент для каждого пользователя. 

**Задачи проекта:**<br>
Рассчитать параметры теста, оценить корректность его проведения и проанализировать результаты эксперимента.<br>

**Описание данных**<br>
Три таблицы:<br>
1. sessions_project_history.csv — таблица с историческими данными по сессиям пользователей на период с 2025-08-11 по 2025-09-23. <br>
2. sessions_project_test_part.csv — таблица с данными за первый день проведения A/B-теста, то есть за 2025-10-14. <br>
3. sessions_project_test.csv — таблица с данными за весь период проведения A/B-теста, то есть с 2025-10-14 по 2025-11-02. <br>

Поля таблиц sessions_project_history.csv, sessions_project_test.csv, sessions_project_test_part.csv:<br>
user_id — идентификатор пользователя;<br>
session_id — идентификатор сессии в приложении;<br>
session_date — дата сессии;<br>
session_start_ts — дата и время начала сессии;<br>
install_date — дата установки приложения;<br>
session_number — порядковый номер сессии для конкретного пользователя;<br>
registration_flag — является ли пользователь зарегистрированным;<br>
page_counter — количество просмотренных страниц во время сессии;<br>
region — регион пользователя;<br>
device — тип устройства пользователя;<br>
test_group — тестовая группа.
